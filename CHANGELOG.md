# Changelog

## Unreleased

## 0.1.0

- Add a GStreamer-only VOD transmuxing and transcoding server for Linux, Windows, Android, and embedded Tauri hosts.
- Add deduplicated source registration, authenticated range relays, resolver request budgets, 429 circuit breaking, and redacted diagnostics.
- Add browser-playable CMAF/HLS output with zero-decode transmuxing, H.264/AAC fallback transcoding, HDR capability handling, and hardware-first codec selection.
- Add finite duration, seeking, startup warming, bounded look-ahead, audio/subtitle track switching, language preferences, and cache limits.
- Add deterministic multi-track, seek, switch-latency, rate-limit, cancellation, browser-output, and cross-platform qualification.
