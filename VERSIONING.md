# Versioning

`air-transcode` follows Semantic Versioning while using `0.MINOR.PATCH` before
1.0. Incompatible HTTP protocol, configuration, or public Rust API changes bump
`MINOR`; compatible fixes and additions bump `PATCH`.

Stable GitHub Releases and crates.io publications use `vX.Y.Z`. Published crate
versions are immutable. The matching `@get-air/transcode` client documents the
server protocol versions it supports.
